# Riyadh Elwalwal - QA Engineer Portfolio

A responsive German/English personal portfolio for QA Engineer Riyadh Elwalwal.

## Run locally

Open `index.html` in a browser. For best results, serve the folder with any static web server.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, for example `riyadh-portfolio`.
2. Upload all files and folders from this package to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.

## Customisation

- Replace `assets/Riyadh-Elwalwal-CV.pdf` whenever the CV changes.
- Edit contact details and text in `index.html`.
- Colours and layout are controlled in `styles.css`.
- English translations are stored in `script.js`.

The contact button uses the visitor's email application and sends to `riyadhelwalwal@gmail.com`.
